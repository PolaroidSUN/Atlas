# Atlas 1.7.5 Alpha

## Executar
1. Extraia o arquivo ZIP para uma pasta nova.
2. Execute `TESTAR_NO_NAVEGADOR.bat` (ou rode `npm install` e `npm run dev`).
3. Para gerar o aplicativo Tauri, use as ferramentas Rust/MSVC necessárias e `npm run tauri:build`.

## Alterações deste pacote
- Linhas de conexão com trechos horizontais/verticais e cantos retos. Para reconectar uma linha existente, arraste uma de suas extremidades para outra porta de um cartão.
- Imagens dentro de cartões: passe o mouse sobre a imagem para ver a borda e as oito alças; arraste uma alça para redimensionar.
- Menu de alinhamento e lista da barra de formatação corrigidos para comandos dentro de células de tabela.

A versão é código-fonte. A execução de testes estáticos não substitui o teste visual no seu navegador.
